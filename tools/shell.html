Zig from Zero to IRON LEDGER

A patient, exercise-driven course in the Zig programming language (version 0.16), starting from the first line you type and ending inside the source of IRON LEDGER, a 31,000-line BattleTech mercenary-company simulator written in pure Zig with no libraries.

This book grew out of a short guide, Learning Zig through IRON LEDGER, which taught the language in seventeen brisk sections and then toured the program's architecture. That guide assumed you already knew a systems language. This book does not. It takes the same destination and walks there slowly, the way a traditional programming book does: one idea per chapter, a complete runnable program for every idea, its real output, the trap that catches beginners, and a set of exercises with solutions you can reveal when you are ready. The original guide's architecture tour survives, expanded, as Part 5, and it is where you will find yourself reading real production code with confidence.

Every program in this book was compiled and run with Zig 0.16 on the day it was written. Zig changes between versions, and 0.16 changed how programs talk to the outside world (the std.Io interface) and how the standard containers are used (lists and maps no longer remember their allocator). Tutorials found on the web will often show older forms that no longer compile. When this book and a web page disagree, trust this book and the compiler, and see Appendix A3 for the translation table.

How to read. Chapters build on each other, so read in order the first time. Every chapter ends with exercises and a short quiz. The exercise files live in the exercises/ folder beside this page, with solutions in each chapter's solutions/ subfolder; type the solutions in yourself rather than copying, and run them. Chapter 0 explains the mechanics. Use the sidebar to jump around later; the buttons at the top of it reveal every answer at once or every subsection heading.
