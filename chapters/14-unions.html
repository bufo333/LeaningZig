14. Unions and tagged unions

In this chapter you will learn the type that IRON LEDGER is built around: the tagged union, a value that is exactly one of several alternatives, each with its own data, and always knows which. You will build them, switch over them with payload captures, modify payloads in place, give them methods, and use them as commands, messages and machine states, ending with a small interpreter. If you know Rust enums, Swift enums with associated values, or Haskell sum types, this is Zig's version.

14.1 Bare unions, briefly

A plain union is a piece of memory that can hold one of several fields, one at a time. It is as big as its largest field, and it does not remember which field you stored.

bare.zig

const std = @import("std");

const Number = union {
    int: i64,
    float: f64,
};

pub fn main() void {
    const n = Number{ .int = 42 };
    std.debug.print("{d}\n", .{n.int});
    std.debug.print("{d} bytes\n", .{@sizeOf(Number)});
}
42
16 bytes

Bare unions are for the rare cases where you are reinterpreting memory on purpose, usually at a C boundary (Chapter 35). For everything else, you want the union to carry its tag, so you can ask it which field is active. That is the tagged union.

14.2 union(enum)

Write union(enum) and Zig generates an enum with one member per field, stores its value alongside the data, and keeps it in sync. Here is IRON LEDGER's terminal key type, trimmed:

tagged.zig

const std = @import("std");

const Key = union(enum) {
    char: u21, // a typed character, with its code point
    f: u8, // F1..F12, with the number
    ctrl: u8, // ctrl + a letter
    enter, // no payload: like an enum member
    escape,
    none,
};

pub fn main() void {
    const keys = [_]Key{
        .{ .char = 'q' },
        .{ .f = 3 },
        .{ .ctrl = 'c' },
        .enter,
        .none,
    };
    for (keys) |k| {
        std.debug.print("{any}\n", .{k});
    }
    std.debug.print("{d} bytes\n", .{@sizeOf(Key)});
}
.{ .char = 113 }
.{ .f = 3 }
.{ .ctrl = 99 }
.{ .enter = void }
.{ .none = void }
8 bytes

Three things to read off this. First, the fields: char: u21 has a payload (which character), f: u8 has a payload (which function key), and enter has none, which makes it behave like a plain enum member. A union can mix both freely; void is the implied payload type of a bare name.

Second, the literals. A field with a payload is built as .{ .char = 'q' }, the same anonymous-literal shape as a struct with one field. A field without one is written like an enum value: .enter. Both coerce to Key from context.

Third, the size: eight bytes, which is a u21 rounded up to four bytes, plus the tag, plus padding. Compared with the bare union's hidden tag, this one is yours to inspect.

Key.enter is not a Key. Writing the type name and a payload-less field, Shape.point, gives you the tag enum's value, not a union value. It looks right and then fails with no field or member function named 'scale' in '@typeInfo(Shape).@"union".tag_type.?' the first time you call a method on it. 
const std = @import("std");

const Shape = union(enum) { circle: f64, point };

pub fn main() void {
    const a = Shape.point; // careful: this is the TAG enum value, not a Shape
    const b: Shape = .point; // this is a Shape
    std.debug.print("{any}\n{any}\n", .{ @TypeOf(a), @TypeOf(b) });
}

Always write union values with an expected type in view: const p: Shape = .point;, or .point directly in an argument or array literal.

14.3 Switching with payload captures

The tag makes switch possible, and the payload comes along in a capture:

switch.zig

const std = @import("std");

const Key = union(enum) {
    char: u21,
    f: u8,
    ctrl: u8,
    enter,
    escape,
    none,
};

fn describe(k: Key) void {
    switch (k) {
        .char => |c| std.debug.print("typed '{u}'\n", .{c}),
        .f => |n| std.debug.print("function key F{d}\n", .{n}),
        .ctrl => |c| std.debug.print("ctrl-{c}\n", .{c}),
        .enter => std.debug.print("enter\n", .{}),
        .escape, .none => std.debug.print("nothing useful\n", .{}),
    }
}

pub fn main() void {
    describe(.{ .char = 'q' });
    describe(.{ .f = 3 });
    describe(.{ .ctrl = 'c' });
    describe(.enter);
    describe(.escape);
}
typed 'q'
function key F3
ctrl-c
enter
nothing useful

Each arm names a tag with the leading dot, and |c| binds the payload of that field, typed correctly: c is a u21 in the .char arm and a u8 in the .ctrl arm. Payload-less arms have no capture. Arms can be grouped with commas as long as they do not try to capture different payload types. ({u} prints a code point as its UTF-8 character.)

Exhaustiveness works exactly as it does for enums, and it is the reason the game uses this type for its commands:

14.4 Asking for the tag

Sometimes you only need to know which alternative is active, not what it holds:

tagquery.zig

const std = @import("std");

const Key = union(enum) { char: u21, f: u8, enter };

pub fn main() void {
    const k = Key{ .f = 5 };
    std.debug.print("{any}\n", .{std.meta.activeTag(k)});
    std.debug.print("{s}\n", .{@tagName(k)});
    std.debug.print("{}\n", .{k == .f}); // compare the tag only
    std.debug.print("{}\n", .{std.meta.activeTag(k) == .char});
    if (k == .f) std.debug.print("F{d}\n", .{k.f}); // safe: we checked
    const Tag = std.meta.Tag(Key); // the enum behind the union
    std.debug.print("{any}\n", .{@typeInfo(Tag).@"enum".fields.len});
}

std.meta.activeTag(k) returns the tag as an enum value. @tagName works directly on the union. And most conveniently, a tagged union compares with == against an enum literal, comparing only the tag: k == .f is true whatever the F-number is. That is the idiom for a quick check before touching a payload, as the if (k == .f) line does. std.meta.Tag(Key) names the generated enum type when you need to store or pass tags around.

14.5 Modifying a payload in place

A capture with |v| is a copy of the payload. To change the payload inside the union, switch on a pointer to the union and capture with |*v|:

mutate.zig

const std = @import("std");

const Damage = union(enum) {
    armor: u16, // points of armor left
    internal: u16, // structure points left
    destroyed,
};

fn hit(d: *Damage, amount: u16) void {
    switch (d.*) {
        .armor => |*left| {
            if (amount < left.*) {
                left.* -= amount; // modify the payload in place
            } else {
                d.* = .{ .internal = 10 }; // replace the whole value
            }
        },
        .internal => |*left| {
            if (amount < left.*) left.* -= amount else d.* = .destroyed;
        },
        .destroyed => {},
    }
}

pub fn main() void {
    var d = Damage{ .armor = 12 };
    for ([_]u16{ 5, 5, 5, 5, 20 }) |amt| {
        hit(&d, amt);
        std.debug.print("{any}\n", .{d});
    }
}
.{ .armor = 7 }
.{ .armor = 2 }
.{ .internal = 10 }
.{ .internal = 5 }
.{ .destroyed = void }

Two kinds of change appear here. left.* -= amount changes the number stored in the active field without changing which field is active. d.* = .{ .internal = 10 } replaces the whole union, tag and all, which is how a value moves from one state to the next. Note that the switch is on d.*, the union itself, and the pointer capture then refers into it; the same shape works on self.* inside a method.

14.6 Methods on unions

Like structs and enums, unions can hold functions. A method that only reads takes the union by value and switches on it; one that modifies takes a pointer:

methods.zig

const std = @import("std");

const Shape = union(enum) {
    circle: f64, // radius
    rect: struct { w: f64, h: f64 },
    point,

    pub fn area(self: Shape) f64 {
        return switch (self) {
            .circle => |r| std.math.pi * r * r,
            .rect => |r| r.w * r.h,
            .point => 0,
        };
    }

    pub fn scale(self: *Shape, k: f64) void {
        switch (self.*) {
            .circle => |*r| r.* *= k,
            .rect => |*r| {
                r.w *= k;
                r.h *= k;
            },
            .point => {},
        }
    }
};

pub fn main() void {
    var shapes = [_]Shape{ .{ .circle = 1 }, .{ .rect = .{ .w = 2, .h = 3 } }, .point };
    for (&shapes) |*s| {
        s.scale(2);
        std.debug.print("{s}: {d:.2}\n", .{ @tagName(s.*), s.area() });
    }
}
circle: 12.57
rect: 24.00
point: 0.00

rect carries an inline struct as its payload, so |r| gives you something with .w and .h. A union with methods that switch on self is Zig's answer to a class hierarchy with a virtual method: one type, every alternative listed, every case handled in one place, no allocation and no pointers. The trade-off is the same one enums make: adding an alternative touches every switch, and the compiler tells you where.

A union may also name an existing enum as its tag, union(Kind), when you want control over the tag's integer values or want to share the enum elsewhere. A tagged union then coerces to that enum:

explicit_tag.zig

const std = @import("std");

const Kind = enum(u8) { text = 1, number = 2, nothing = 3 };

const Value = union(Kind) {
    text: []const u8,
    number: i64,
    nothing,
};

pub fn main() void {
    const v = Value{ .number = 7 };
    std.debug.print("{d}\n", .{@intFromEnum(std.meta.activeTag(v))});
    const k: Kind = v; // a tagged union coerces to its tag enum
    std.debug.print("{any}\n", .{k});
}

14.7 Commands, messages and state machines

The most useful thing to do with a tagged union is to make the set of things that can happen into a type. Here is a tiny version of IRON LEDGER's command loop:

commands.zig

const std = @import("std");

const Command = union(enum) {
    advance_day,
    advance_days: u32,
    hire: struct { name: []const u8, salary: i64 },
    fire: u32,
    rename: []const u8,
};

const State = struct {
    day: u32 = 1,
    name: []const u8 = "Unnamed Company",
    staff: u32 = 0,
    funds: i64 = 1_000_000,
};

fn execute(s: *State, cmd: Command) void {
    switch (cmd) {
        .advance_day => s.day += 1,
        .advance_days => |n| s.day += n,
        .hire => |h| {
            s.staff += 1;
            s.funds -= h.salary;
            std.debug.print("hired {s}\n", .{h.name});
        },
        .fire => |id| {
            s.staff -= 1;
            std.debug.print("fired #{d}\n", .{id});
        },
        .rename => |new_name| s.name = new_name,
    }
}

pub fn main() void {
    var s = State{};
    const script = [_]Command{
        .{ .rename = "Grey Death Legion" },
        .{ .hire = .{ .name = "Kai", .salary = 1_500 } },
        .{ .hire = .{ .name = "Nat", .salary = 800 } },
        .advance_day,
        .{ .advance_days = 30 },
        .{ .fire = 2 },
    };
    for (script) |cmd| execute(&s, cmd);
    std.debug.print("{s}: day {d}, {d} staff, {d} C-bills\n", .{
        s.name, s.day, s.staff, s.funds,
    });
}
hired Kai
hired Nat
fired #2
Grey Death Legion: day 32, 1 staff, 997700 C-bills

Every possible request is a Command; the state is only ever changed inside execute; and the script is plain data, an array of commands, that can be built by a parser, read from a file, or written by a test. That separation, where the union is the only way in, is the architecture of the whole game (Chapter 42), and you have now seen all of the language it takes.

The same trick describes a value that changes state over time. Damage in 14.5 was a state machine: armor, then internal, then destroyed, each state carrying only the data that state needs. Compare that with a struct holding an armor field, an internal field and a destroyed flag, where nothing stops destroyed = true alongside armor = 12.

Unions can also refer to themselves through pointers, which is how tree-shaped data is built. An arithmetic expression is a number, or a negation of an expression, or a sum or product of two:

expr.zig

const std = @import("std");

const Expr = union(enum) {
    num: i64,
    neg: *const Expr,
    add: struct { l: *const Expr, r: *const Expr },
    mul: struct { l: *const Expr, r: *const Expr },

    pub fn eval(self: Expr) i64 {
        return switch (self) {
            .num => |n| n,
            .neg => |e| -e.eval(),
            .add => |p| p.l.eval() + p.r.eval(),
            .mul => |p| p.l.eval() * p.r.eval(),
        };
    }
};

pub fn main() void {
    // (2 + 3) * -4
    const two = Expr{ .num = 2 };
    const three = Expr{ .num = 3 };
    const four = Expr{ .num = 4 };
    const sum = Expr{ .add = .{ .l = &two, .r = &three } };
    const neg4 = Expr{ .neg = &four };
    const prod = Expr{ .mul = .{ .l = &sum, .r = &neg4 } };
    std.debug.print("{d}\n", .{prod.eval()});
}
-20

The payloads hold *const Expr, pointers to other expressions, because a union cannot contain itself by value (it would be infinitely large). The nodes here are locals whose addresses are taken; a real interpreter would allocate them (Chapter 19). eval is a method that recurses through the switch, four lines for a whole evaluator.

pub const Command = union(enum) {
    /// End the turn: advance one day.
    advance_day,
    advance_days: u32,
    hire: struct {

    switch (cmd) {
        .advance_day => return advance(gs, 1),
        .advance_days => |n| return advance(gs, n),
        .hire => |h| {
            const id = try gs.hirePerson(h.first, h.last, h.role);

Exercise 14.1 · Shapes with methods warm-up

Give Shape four methods: area, perimeter, an in-place scale using |*v| captures, and simplify, which turns an equal-sided rect into a square. Name the file: exercises/14-unions/ex1_shapes.zig.

Solution 
//! Chapter 14, exercise 1: a tagged union with methods.
//! Run with:  zig test ex1_shapes.zig
//! Goal: make every test pass without changing the tests.
const std = @import("std");

const Shape = union(enum) {
    circle: f64, // radius
    rect: struct { w: f64, h: f64 },
    square: f64, // side
    point,

    pub fn area(self: Shape) f64 {
        return switch (self) {
            .circle => |r| std.math.pi * r * r,
            .rect => |r| r.w * r.h,
            .square => |s| s * s,
            .point => 0,
        };
    }

    pub fn perimeter(self: Shape) f64 {
        return switch (self) {
            .circle => |r| 2 * std.math.pi * r,
            .rect => |r| 2 * (r.w + r.h),
            .square => |s| 4 * s,
            .point => 0,
        };
    }

    /// Scale every dimension by k, in place.
    pub fn scale(self: *Shape, k: f64) void {
        switch (self.*) {
            .circle => |*r| r.* *= k,
            .rect => |*r| {
                r.w *= k;
                r.h *= k;
            },
            .square => |*s| s.* *= k,
            .point => {},
        }
    }

    /// A rect whose sides are equal is really a square; normalise it.
    pub fn simplify(self: Shape) Shape {
        return switch (self) {
            .rect => |r| if (r.w == r.h) Shape{ .square = r.w } else self,
            else => self,
        };
    }
};

test "area and perimeter" {
    try std.testing.expectEqual(@as(f64, 6), (Shape{ .rect = .{ .w = 2, .h = 3 } }).area());
    try std.testing.expectEqual(@as(f64, 10), (Shape{ .rect = .{ .w = 2, .h = 3 } }).perimeter());
    try std.testing.expectEqual(@as(f64, 9), (Shape{ .square = 3 }).area());
    try std.testing.expectEqual(@as(f64, 0), (Shape{ .point = {} }).area());
    try std.testing.expectApproxEqAbs(@as(f64, 3.14159), (Shape{ .circle = 1 }).area(), 0.001);
}

test "scale in place" {
    var s = Shape{ .rect = .{ .w = 2, .h = 3 } };
    s.scale(2);
    try std.testing.expectEqual(@as(f64, 24), s.area());
    var p: Shape = .point;
    p.scale(100);
    try std.testing.expect(p == .point);
}

test "simplify" {
    const sq = (Shape{ .rect = .{ .w = 2, .h = 2 } }).simplify();
    try std.testing.expect(sq == .square);
    try std.testing.expectEqual(@as(f64, 2), sq.square);
    const r = (Shape{ .rect = .{ .w = 2, .h = 3 } }).simplify();
    try std.testing.expect(r == .rect);
}

scale switches on self.* and captures pointers so the multiplication lands inside the union. simplify uses else => self: only rect needs thought, and returning the value unchanged is the correct default for every future variant. Note var p: Shape = .point; in the test, not Shape.point, for the reason in 14.2.

Exercise 14.2 · Decoding keys practice

Rebuild the byte-to-key decoder from src/tui/term.zig: a switch over a u8 with ranges and lists producing Key values; a describe that prints a key into a buffer; and countChars, which compares tags. Name the file: exercises/14-unions/ex2_keys.zig.

Solution 
//! Chapter 14, exercise 2: decoding bytes into keys.
//! Run with:  zig test ex2_keys.zig
//! Goal: make every test pass without changing the tests.
const std = @import("std");

/// IRON LEDGER's terminal key type, trimmed.
const Key = union(enum) {
    char: u21,
    enter,
    escape,
    tab,
    backspace,
    ctrl: u8, // 'a'..'z'
    none,
};

/// Decode one raw byte the way src/tui/term.zig does.
fn decode(b: u8) Key {
    return switch (b) {
        0x1b => .escape,
        '\r', '\n' => .enter,
        '\t' => .tab,
        0x7f, 0x08 => .backspace,
        1...7, 11, 12, 14...26 => .{ .ctrl = 'a' + b - 1 },
        else => .{ .char = b },
    };
}

/// A short human name for a key, into buf.
fn describe(k: Key, buf: []u8) ![]const u8 {
    return switch (k) {
        .char => |c| std.fmt.bufPrint(buf, "'{u}'", .{c}),
        .ctrl => |c| std.fmt.bufPrint(buf, "ctrl-{c}", .{c}),
        .enter, .escape, .tab, .backspace, .none => @tagName(k),
    };
}

/// Count how many of the keys are printable characters.
fn countChars(keys: []const Key) usize {
    var n: usize = 0;
    for (keys) |k| {
        if (k == .char) n += 1;
    }
    return n;
}

test "decode" {
    try std.testing.expectEqual(Key.escape, decode(0x1b));
    try std.testing.expectEqual(Key.enter, decode('\n'));
    try std.testing.expectEqual(Key.backspace, decode(0x7f));
    try std.testing.expectEqual(Key{ .ctrl = 'c' }, decode(3));
    try std.testing.expectEqual(Key{ .ctrl = 'z' }, decode(26));
    try std.testing.expectEqual(Key{ .char = 'q' }, decode('q'));
}

test "describe" {
    var buf: [16]u8 = undefined;
    try std.testing.expectEqualStrings("'q'", try describe(.{ .char = 'q' }, &buf));
    try std.testing.expectEqualStrings("ctrl-c", try describe(.{ .ctrl = 'c' }, &buf));
    try std.testing.expectEqualStrings("escape", try describe(.escape, &buf));
}

test "countChars" {
    const keys = [_]Key{ .{ .char = 'a' }, .enter, .{ .char = 'b' }, .{ .ctrl = 'c' }, .none };
    try std.testing.expectEqual(@as(usize, 2), countChars(&keys));
}

1...7, 11, 12, 14...26 is the game's own arm: the control characters that are not tab, newline or carriage return. The describe switch mixes arms that return a formatted slice with arms that return @tagName(k); both are []const u8, so the switch has one type.

Exercise 14.3 · Commands practice

A Command union drives a small State. Implement execute (one exhaustive switch, returning errors for impossible requests) and parse, which turns a line of text into a command or null. The last test runs a script of six lines through both. Name the file: exercises/14-unions/ex3_commands.zig.

Solution 
//! Chapter 14, exercise 3: commands as a tagged union.
//! Run with:  zig test ex3_commands.zig
//! Goal: make every test pass without changing the tests.
const std = @import("std");

const Command = union(enum) {
    advance_day,
    advance_days: u32,
    hire: struct { name: []const u8, salary: i64 },
    fire: u32, // staff index
    deposit: i64,
};

const Error = error{ NoSuchPerson, InsufficientFunds, TooManyStaff };

const State = struct {
    day: u32 = 1,
    funds: i64 = 10_000,
    staff: [4]?[]const u8 = .{ null, null, null, null },

    fn headcount(self: State) usize {
        var n: usize = 0;
        for (self.staff) |s| {
            if (s != null) n += 1;
        }
        return n;
    }
};

fn execute(s: *State, cmd: Command) Error!void {
    switch (cmd) {
        .advance_day => s.day += 1,
        .advance_days => |n| s.day += n,
        .hire => |h| {
            if (h.salary > s.funds) return error.InsufficientFunds;
            for (&s.staff) |*slot| {
                if (slot.* == null) {
                    slot.* = h.name;
                    s.funds -= h.salary;
                    return;
                }
            }
            return error.TooManyStaff;
        },
        .fire => |i| {
            if (i >= s.staff.len or s.staff[i] == null) return error.NoSuchPerson;
            s.staff[i] = null;
        },
        .deposit => |amt| s.funds += amt,
    }
}

/// Parse an optional token as a number; a missing token is an error too.
fn num(comptime T: type, tok: ?[]const u8) !T {
    return std.fmt.parseInt(T, tok orelse "", 10);
}

/// Parse one line of text into a command, or null for an unknown verb.
fn parse(line: []const u8) !?Command {
    var it = std.mem.tokenizeScalar(u8, line, ' ');
    const verb = it.next() orelse return null;
    const eq = std.mem.eql;
    if (eq(u8, verb, "day")) return .advance_day;
    if (eq(u8, verb, "days")) return .{ .advance_days = try num(u32, it.next()) };
    if (eq(u8, verb, "fire")) return .{ .fire = try num(u32, it.next()) };
    if (eq(u8, verb, "deposit")) return .{ .deposit = try num(i64, it.next()) };
    if (eq(u8, verb, "hire")) {
        const name = it.next() orelse return error.InvalidCharacter;
        const salary = try num(i64, it.next());
        return .{ .hire = .{ .name = name, .salary = salary } };
    }
    return null;
}

test "execute" {
    var s = State{};
    try execute(&s, .{ .hire = .{ .name = "Kai", .salary = 1_500 } });
    try execute(&s, .{ .advance_days = 10 });
    try std.testing.expectEqual(@as(u32, 11), s.day);
    try std.testing.expectEqual(@as(i64, 8_500), s.funds);
    try std.testing.expectEqual(@as(usize, 1), s.headcount());
    try execute(&s, .{ .fire = 0 });
    try std.testing.expectEqual(@as(usize, 0), s.headcount());
}

test "errors" {
    var s = State{ .funds = 100 };
    const kai: Command = .{ .hire = .{ .name = "Kai", .salary = 1_500 } };
    try std.testing.expectError(error.InsufficientFunds, execute(&s, kai));
    try std.testing.expectError(error.NoSuchPerson, execute(&s, .{ .fire = 2 }));
    s.funds = 1_000_000;
    for ([_][]const u8{ "a", "b", "c", "d" }) |n| {
        try execute(&s, .{ .hire = .{ .name = n, .salary = 1 } });
    }
    const one_more: Command = .{ .hire = .{ .name = "e", .salary = 1 } };
    try std.testing.expectError(error.TooManyStaff, execute(&s, one_more));
}

test "parse" {
    try std.testing.expectEqual(@as(?Command, .advance_day), try parse("day"));
    try std.testing.expectEqual(@as(?Command, .{ .advance_days = 30 }), try parse("days 30"));
    try std.testing.expectEqual(@as(?Command, null), try parse("dance"));
    try std.testing.expectError(error.InvalidCharacter, parse("days thirty"));
    const h = (try parse("hire Kai 1500")).?;
    try std.testing.expectEqualStrings("Kai", h.hire.name);
    try std.testing.expectEqual(@as(i64, 1500), h.hire.salary);
}

test "a script" {
    var s = State{};
    const lines = [_][]const u8{
        "hire Kai 1500", "hire Nat 800", "deposit 5000", "days 30", "fire 1", "day",
    };
    for (lines) |l| {
        const cmd = (try parse(l)) orelse continue;
        try execute(&s, cmd);
    }
    try std.testing.expectEqual(@as(u32, 32), s.day);
    try std.testing.expectEqual(@as(i64, 12_700), s.funds);
    try std.testing.expectEqual(@as(usize, 1), s.headcount());
}

This is the guide's parseCommand in miniature, down to the const eq = std.mem.eql; shortcut and the !?Command return type: an error for a malformed number, null for an unknown verb, a command otherwise. expectEqual compares tagged unions by tag and payload, so .{ .advance_days = 30 } can be checked directly.

Exercise 14.4 · A stack-machine interpreter challenge

Op is an instruction set: push, arithmetic, dup, swap, a conditional jump and halt. Write the switch inside Machine.run. The tests include a countdown loop, so the jump must work, and a step limit turns an endless program into error.NoHalt. Name the file: exercises/14-unions/ex4_interpreter.zig.

Solution 
//! Chapter 14, exercise 4: a tiny stack-machine interpreter (challenge).
//! Run with:  zig test ex4_interpreter.zig
//! Goal: make every test pass without changing the tests.
const std = @import("std");

/// One instruction for a stack machine.
const Op = union(enum) {
    push: i64,
    add,
    sub,
    mul,
    dup,
    swap,
    jump_if_zero: usize, // pop; if zero, jump to this instruction index
    halt,
};

const Error = error{ StackUnderflow, StackOverflow, BadJump, NoHalt };

const Machine = struct {
    stack: [16]i64 = undefined,
    sp: usize = 0, // number of values on the stack
    pc: usize = 0, // index of the next instruction
    steps: usize = 0,

    fn push(self: *Machine, v: i64) Error!void {
        if (self.sp == self.stack.len) return error.StackOverflow;
        self.stack[self.sp] = v;
        self.sp += 1;
    }

    fn pop(self: *Machine) Error!i64 {
        if (self.sp == 0) return error.StackUnderflow;
        self.sp -= 1;
        return self.stack[self.sp];
    }

    /// Run until halt. Returns the top of the stack (or 0 if empty).
    fn run(self: *Machine, program: []const Op) Error!i64 {
        while (self.pc < program.len) {
            const op = program[self.pc];
            self.pc += 1;
            self.steps += 1;
            if (self.steps > 10_000) return error.NoHalt;
            switch (op) {
                .push => |v| try self.push(v),
                .add => try self.push(try self.pop() + try self.pop()),
                .mul => try self.push(try self.pop() * try self.pop()),
                .sub => {
                    const b = try self.pop();
                    const a = try self.pop();
                    try self.push(a - b);
                },
                .dup => {
                    const a = try self.pop();
                    try self.push(a);
                    try self.push(a);
                },
                .swap => {
                    const b = try self.pop();
                    const a = try self.pop();
                    try self.push(b);
                    try self.push(a);
                },
                .jump_if_zero => |target| {
                    if (target > program.len) return error.BadJump;
                    if ((try self.pop()) == 0) self.pc = target;
                },
                .halt => return if (self.sp == 0) 0 else self.stack[self.sp - 1],
            }
        }
        return error.NoHalt;
    }
};

fn runProgram(program: []const Op) Error!i64 {
    var m = Machine{};
    return m.run(program);
}

test "arithmetic" {
    // (2 + 3) * 4 - 1
    const prog = [_]Op{
        .{ .push = 2 }, .{ .push = 3 }, .add, .{ .push = 4 }, .mul, .{ .push = 1 }, .sub, .halt,
    };
    try std.testing.expectEqual(@as(i64, 19), try runProgram(&prog));
}

test "dup and swap" {
    const prog = [_]Op{ .{ .push = 7 }, .dup, .mul, .{ .push = 100 }, .swap, .sub, .halt };
    // swap turns [49, 100] into [100, 49], so sub computes 100 - 49
    try std.testing.expectEqual(@as(i64, 100 - 49), try runProgram(&prog));
}

test "errors" {
    try std.testing.expectError(error.StackUnderflow, runProgram(&[_]Op{ .add, .halt }));
    try std.testing.expectError(error.NoHalt, runProgram(&[_]Op{.{ .push = 1 }}));
    const bad = [_]Op{ .{ .push = 0 }, .{ .jump_if_zero = 99 }, .halt };
    try std.testing.expectError(error.BadJump, runProgram(&bad));
}

test "countdown loop" {
    // n = 5; while (n != 0) n -= 1; leaves 0 on the stack.
    const prog = [_]Op{
        .{ .push = 5 }, // 0
        .dup, // 1: copy n so the test does not consume it
        .{ .jump_if_zero = 7 }, // 2: if n == 0 go to halt
        .{ .push = 1 }, // 3
        .sub, // 4: n = n - 1
        .{ .push = 0 }, // 5
        .{ .jump_if_zero = 1 }, // 6: always jumps (0 is zero)
        .halt, // 7
    };
    var m = Machine{};
    try std.testing.expectEqual(@as(i64, 0), try m.run(&prog));
    try std.testing.expect(m.steps < 100);
}

Every instruction is one arm. sub and swap pop in the right order (b first, since it was pushed last), which the dup and swap test checks: 100 - 49, not 49 - 100. halt is the only arm that returns a value; every other path returns an error, so the function's result type is Error!i64 and the tests use try and expectError as usual.

Check your understanding

  1. What does a tagged union store that a bare union does not?
    AnswerAn enum tag saying which field is active, kept in sync automatically and available to switch, == against a literal, @tagName and std.meta.activeTag.
  2. How do you build a Key holding ctrl-c, and one holding enter?
    Answer.{ .ctrl = 'c' } and .enter, both with a Key expected from context (a typed variable, a parameter, an array element).
  3. What is the difference between |v| and |*v| in a switch arm?
    Answer|v| copies the payload; |*v| gives a pointer to it, which requires switching on a pointer's target (switch (p.*)) and lets you modify the payload in place.
  4. What does k == .f compare?
    AnswerOnly the tag. It is true for any Key whose active field is f, regardless of payload.
  5. Why does reading k.f when k holds .char not silently return garbage?
    AnswerSafe builds check the tag on every field access: a compile error when the active field is known, a panic otherwise.
  6. Why is Shape.point a trap?
    AnswerIt names the generated tag enum's value, not a Shape. Use const p: Shape = .point; so the union type is expected.
  7. Why must a self-referential union hold *const Expr rather than Expr?
    AnswerA value containing itself would have infinite size. A pointer has a fixed size and can refer to another node stored elsewhere.
What you learned.
  • A bare union is one-of-several without a remembered tag; use it only for deliberate memory reinterpretation.
  • union(enum) { a: T, b: U, c } generates and stores a tag; payload-less fields act like enum members.
  • Build with .{ .a = value } or .c where the union type is expected; Type.c is the tag enum, not the union.
  • switch is exhaustive and captures payloads with |v|; |*v| on switch (p.*) modifies in place; assigning a new literal changes state.
  • k == .tag, @tagName(k), std.meta.activeTag(k) and std.meta.Tag(T) work with the tag alone.
  • Unions take methods like structs; union(SomeEnum) uses an explicit tag type and coerces to it.
  • Commands, messages, states and expression trees are all tagged unions; IRON LEDGER's Command is the only way into its game state.
