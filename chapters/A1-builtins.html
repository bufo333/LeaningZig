Appendix A1. Builtin functions cheat sheet

This appendix lists every builtin used in the course, grouped by purpose. A builtin is a function whose name starts with @; it is part of the language, not the standard library, and it is documented in the language reference rather than in std. Every row was compiled with Zig 0.16.0 while this appendix was written. "Signature" is a sketch, not the formal grammar: T is a type, x a value, and the result type is often inferred from context (write const n: u8 = @intCast(x) or @as(u8, @intCast(x))).

How result types work. Many casts take no type argument. The result type comes from where the expression is used: a typed const, a function parameter, a struct field, or an explicit @as(T, …). If the compiler says "must have a known result type", wrap the call in @as. This is the biggest difference from tutorials written for Zig 0.10 and earlier, where casts were written @intCast(T, x).

Two things that look like builtins but are not: unreachable is a keyword (an expression of type noreturn that asserts the point is never reached), and undefined is a keyword too (a value you promise to overwrite before reading).
