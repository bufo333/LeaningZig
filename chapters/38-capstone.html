38. Capstone: a mercenary ledger from scratch

In this chapter you will build a complete program, "Small Ledger", a command-line simulator of a mercenary company's payroll, in six stages. Each stage is a single file that compiles and passes its tests on its own, and each adds one layer: types, a company with commands, a ledger, a calendar tick, seeded random events, and finally an interactive loop with save and load. By the end you will have written, in about five hundred lines, a miniature of IRON LEDGER's architecture, and the next Part of this book, which reads the real game, will feel like visiting a bigger version of your own house.

38.1 What we are building, and the shape of it

Small Ledger is a program you talk to. You hire people by name and role, advance the calendar, and watch money leave on payday. Random events nudge morale, morale nudges pay, and everything can be saved to a file and loaded back. Here is a session with the finished program:

$ printf 'hire Grayson mekwarrior\nhire Clay tech\nadvance 31\nledger\nsave ledger.sav\nquit\n' | zig run ex6_repl.zig
> hired Grayson as mekwarrior (id 1)
> hired Clay as tech (id 2)
> advanced 31 days to 3025-02-01, funds 47746
> day 31  -2254  payroll  monthly payroll
balance 47746
> saved ledger.sav
> bye

(Two people whose base pay adds up to 2300 were paid 2254 because on day 15 the dice rolled a 2 and morale dropped a point. The seed is fixed, so you will get exactly these numbers.)

The architecture has one rule, borrowed directly from the game: a pure core, and I/O at the edges. The core is a Company struct and an execute(company, command) function. It never reads a file, never reads the clock, never touches stdin. It takes values and returns values or errors. Around it sits a thin edge: a parser that turns text into commands, a printer that turns results into text, and save/load functions that hold the io. The core is where all the rules live, and because it is pure, all of it is testable with zig test and no fixtures.

Each stage is exercises/38-capstone/exN_name.zig. The starters give you the tests and the skeleton; you fill in the bodies. The solutions are complete files, and each stage's solution contains the previous stage's code, so if you get stuck you can start the next stage from the solution of the one before. 38.2 Stage 1: the vocabulary

Every program has a handful of types that everything else is written in terms of. Get them right first, alone, with tests, before there is any behaviour to distract you.

Money is an integer. Not a float: floats cannot represent 0.1 exactly, and a ledger that drifts by a C-bill over a thousand transactions is a ledger nobody trusts (Chapter 5). So CBills = i64, and percentages are basis points, hundredths of a percent, so that "plus 10 percent" is applyBp(x, 11_000) and stays in integer arithmetic. Identifiers are non-exhaustive enums over u32: a PersonId is a number, but the compiler will not let you pass it where a u32 or another ID type is expected (Chapter 13). Roles are an ordinary enum with a method. A person is a struct with a default for the field that starts at zero.

Write these, then make the tests pass. Notice the test for morale: a person at morale +5 earns 2 percent per point more, and the arithmetic must be exact.

//! Chapter 38, stage 1: the vocabulary of Small Ledger.
//! Run with:  zig test ex1_types.zig
//! Goal: define CBills, applyBp, PersonId, Role with baseSalary, and
//! Person with monthlySalary, so the tests pass.

const std = @import("std");

/// All money is integer C-bills. No floats in the ledger, ever.
pub const CBills = i64;

/// Basis points: 10_000 bp is x1.0. All multipliers go through this so
/// the arithmetic is integer and reproducible.
pub const Bp = i64;

pub fn applyBp(amount: CBills, bp: Bp) CBills {
    return @divTrunc(amount * bp, 10_000);
}

/// A typed ID: impossible to mix up with a plain integer or another ID.
pub const PersonId = enum(u32) { none = 0, _ };

pub const Role = enum {
    mekwarrior,
    tech,
    medic,
    admin,

    /// Monthly base pay.
    pub fn baseSalary(self: Role) CBills {
        return switch (self) {
            .mekwarrior => 1_500,
            .tech => 800,
            .medic => 400,
            .admin => 500,
        };
    }
};

pub const Person = struct {
    id: PersonId,
    name: []const u8,
    role: Role,
    hired_day: u32,
    /// -10 (mutinous) to +10 (devoted). Each point is 2 percent of pay.
    morale: i8 = 0,

    /// Base pay adjusted by morale: +2 percent per point.
    pub fn monthlySalary(self: Person) CBills {
        const bp: Bp = 10_000 + @as(Bp, self.morale) * 200;
        return applyBp(self.role.baseSalary(), bp);
    }
};

test "basis points stay in integers" {
    try std.testing.expectEqual(@as(CBills, 1_500), applyBp(1_500, 10_000));
    try std.testing.expectEqual(@as(CBills, 1_650), applyBp(1_500, 11_000));
    try std.testing.expectEqual(@as(CBills, 900), applyBp(1_500, 6_000));
}

test "typed ids are distinct values" {
    const a: PersonId = @enumFromInt(1);
    const b: PersonId = @enumFromInt(2);
    try std.testing.expect(a != b);
    try std.testing.expect(a != .none);
    try std.testing.expectEqual(@as(u32, 2), @intFromEnum(b));
}

test "salary follows role and morale" {
    var p: Person = .{ .id = @enumFromInt(1), .name = "Grayson", .role = .mekwarrior, .hired_day = 0 };
    try std.testing.expectEqual(@as(CBills, 1_500), p.monthlySalary());
    p.morale = 5;
    try std.testing.expectEqual(@as(CBills, 1_650), p.monthlySalary());
    p.morale = -10;
    try std.testing.expectEqual(@as(CBills, 1_200), p.monthlySalary());
}

Two details deserve a look. monthlySalary builds the multiplier as 10_000 + morale * 200, so morale -10 is 8000 bp (80 percent) and +10 is 12000. And the cast @as(Bp, self.morale) widens the i8 before multiplying, because i8 * 200 would overflow. This is the game's Person.monthlySalary in miniature; the real one multiplies three factors, role, experience and rank, all in basis points.

38.3 Stage 2: a Company and its commands

The state comes next. A Company owns a list of people, a running ID counter and a treasury. The question every stateful program must answer is who frees the memory, and the answer here is the same as the game's: an arena. The company creates one arena in init, every name and every list grows out of it, and deinit frees the lot in one call (Chapter 20). No per-person destructor, no double free, no forgotten free.

pub const Error = error{ UnknownPerson, EmptyName, OutOfMemory };

pub const Company = struct {
    arena: std.heap.ArenaAllocator,
    people: std.ArrayList(Person) = .empty,
    next_id: u32 = 1,
    day: u32 = 0,
    funds: CBills,

    pub const Options = struct {
        funds: CBills = 50_000,
    };

    pub fn init(gpa: std.mem.Allocator, opts: Options) Company {
        return .{
            .arena = std.heap.ArenaAllocator.init(gpa),
            .funds = opts.funds,
        };
    }

    pub fn deinit(self: *Company) void {
        self.arena.deinit();
    }

    /// Every allocation the company makes comes from here and dies in deinit.
    pub fn allocator(self: *Company) std.mem.Allocator {
        return self.arena.allocator();
    }

    pub fn find(self: *Company, id: PersonId) ?*Person {
        for (self.people.items) |*p| if (p.id == id) return p;
        return null;
    }

    fn today(self: *Company) u32 {
        return self.day;
    }

    pub fn hire(self: *Company, name: []const u8, role: Role) Error!PersonId {
        if (name.len == 0) return error.EmptyName;
        const id: PersonId = @enumFromInt(self.next_id);
        self.next_id += 1;
        const owned = try self.allocator().dupe(u8, name);
        try self.people.append(self.allocator(), .{
            .id = id,
            .name = owned,
            .role = role,
            .hired_day = self.today(),
        });
        return id;
    }

    pub fn fire(self: *Company, id: PersonId) Error!void {
        for (self.people.items, 0..) |p, i| {
            if (p.id == id) {
                _ = self.people.orderedRemove(i);
                return;
            }
        }
        return error.UnknownPerson;
    }
};

hire copies the name into the arena with dupe. This matters: the caller's string might be a buffer that gets reused (the REPL's line buffer will be exactly that), so the company must own its copy. The test checks this by mutating the caller's buffer after hiring. fire uses orderedRemove rather than swapRemove, because the order of the roster is part of the state we will hash later, and it must not depend on deletion history.

The second half of the stage is the command layer. A command is a tagged union, one variant per thing a user can ask for; execute is one switch that dispatches to the company's methods and returns a Result or an error from a named set (Chapter 14, Chapter 16).

pub const Command = union(enum) {
    hire: struct { name: []const u8, role: Role },
    fire: PersonId,
};

pub const Result = union(enum) {
    hired: PersonId,
    fired,
};

pub fn execute(co: *Company, cmd: Command) Error!Result {
    switch (cmd) {
        .hire => |h| return .{ .hired = try co.hire(h.name, h.role) },
        .fire => |id| {
            try co.fire(id);
            return .fired;
        },
    }
}

Why the extra layer, when the REPL could call co.hire directly? Because a union of commands is data. It can be stored in an array (a script), compared, logged, replayed, sent over a wire. Stage 5's golden-master test is an array of commands run twice. The game's Command union has about forty variants and its execute is the single entry point for the TUI, the CLI and every test.

38.4 Stage 3: the ledger

Money must move in exactly one way. If funds can be changed by any line of code that feels like it, then the ledger and the balance will disagree eventually and you will not know which is right. So: a Transaction record, a Ledger that is a list of them, and one method on Company that appends a record and adjusts the balance in the same breath.

pub const Category = enum { payroll, severance, contract, event };

pub const Transaction = struct {
    day: u32,
    amount: CBills, // income +, expense -
    category: Category,
    note: []const u8 = "",
};

pub const Ledger = struct {
    transactions: std.ArrayList(Transaction) = .empty,

    pub fn post(self: *Ledger, alloc: std.mem.Allocator, txn: Transaction) !void {
        try self.transactions.append(alloc, txn);
    }

    /// Sum of every transaction: what the ledger says we have gained or lost.
    pub fn balance(self: Ledger) CBills {
        var total: CBills = 0;
        for (self.transactions.items) |t| total += t.amount;
        return total;
    }

    pub fn sumCategory(self: Ledger, cat: Category) CBills {
        var total: CBills = 0;
        for (self.transactions.items) |t| if (t.category == cat) {
            total += t.amount;
        };
        return total;
    }
};
/// The only way money moves: a ledger entry and the balance, in lockstep.
pub fn postTransaction(self: *Company, txn: Transaction) Error!void {
    try self.ledger.post(self.allocator(), txn);
    self.funds += txn.amount;
}

pub fn monthlyPayroll(self: *Company) CBills {
    var total: CBills = 0;
    for (self.people.items) |p| total += p.monthlySalary();
    return total;
}

pub fn runPayroll(self: *Company) Error!void {
    const payroll = self.monthlyPayroll();
    if (payroll == 0) return;
    try self.postTransaction(.{
        .day = self.today(),
        .amount = -payroll,
        .category = .payroll,
        .note = "monthly payroll",
    });
}

The invariant this buys is stated as a test: funds == starting_funds + ledger.balance(), always. Firing now posts a severance transaction (one month's pay) before removing the person:

pub fn fire(self: *Company, id: PersonId) Error!void {
    for (self.people.items, 0..) |p, i| {
        if (p.id == id) {
            try self.postTransaction(.{
                .day = self.today(),
                .amount = -p.monthlySalary(),
                .category = .severance,
                .note = p.name,
            });
            _ = self.people.orderedRemove(i);
            return;
        }
    }
    return error.UnknownPerson;
}

The note field holds the person's name, which lives in the arena, so the string stays valid after the person is removed from the list. That is another quiet benefit of the arena: nothing you have ever allocated goes away until the company does, so references between records are always safe.

The tests count paydays: 31 days from January 1st is exactly one; 365 days is exactly twelve; and the company's start date is a payday that does not pay, because payroll runs after the clock advances. That last point is the kind of off-by-one a test settles once and for all.

38.6 Stage 5: dice, and the golden master

Now the simulation gets a random element, and with it the discipline that keeps randomness from ruining testability. The company gets a seed in its Options, an Rng with named streams (the miniature you built in Exercise 34.5), and a log. advanceDay gains an events phase before finances:

/// One campaign day, in a fixed order of phases: events, then finances.
pub fn advanceDay(co: *Company) Error!void {
    co.clock.advance();
    try runEvents(co);
    if (co.clock.date.isPayday()) try co.runPayroll();
}

/// The morale event: 2d6 on the events stream every day. Snake eyes and
/// boxcars are the only rolls that do anything, so most days are quiet.
fn runEvents(co: *Company) Error!void {
    const roll = co.rng.roll2d6(.events);
    switch (roll) {
        2 => {
            for (co.people.items) |*p| p.morale = @max(p.morale - 1, -10);
            try co.logf("day {d}: grumbling in the barracks (rolled 2), morale -1", .{co.clock.day_index});
        },
        12 => {
            for (co.people.items) |*p| p.morale = @min(p.morale + 1, 10);
            try co.logf("day {d}: a good day (rolled 12), morale +1", .{co.clock.day_index});
        },
        else => {},
    }
}

Every day rolls 2d6 on the .events stream. A 2 lowers everyone's morale by a point, a 12 raises it, anything else is a quiet day, so roughly one day in eighteen something happens. Morale is clamped with @max and @min. The log is a list of strings in the arena, built with allocPrint.

Then the test that makes the whole design pay off. A hash method folds the state that matters (the day, the funds, every person's ID, name, morale and hire date, and the number of transactions) into one 64-bit number with std.hash.Wyhash:

/// A 64-bit fingerprint of everything that matters. Two companies with
/// the same seed and the same commands must produce the same hash.
pub fn hash(self: *Company) u64 {
    var h = std.hash.Wyhash.init(0);
    h.update(std.mem.asBytes(&self.clock.day_index));
    h.update(std.mem.asBytes(&self.funds));
    for (self.people.items) |p| {
        h.update(std.mem.asBytes(&p.id));
        h.update(p.name);
        h.update(std.mem.asBytes(&p.morale));
        h.update(std.mem.asBytes(&p.hired_day));
    }
    const n: u64 = self.ledger.transactions.items.len;
    h.update(std.mem.asBytes(&n));
    return h.final();
}

const std = @import("std");

/// All money is integer C-bills. No floats in the ledger, ever.
pub const CBills = i64;

/// Basis points: 10_000 bp is x1.0.
pub const Bp = i64;

pub fn applyBp(amount: CBills, bp: Bp) CBills {
    return @divTrunc(amount * bp, 10_000);
}

pub const PersonId = enum(u32) { none = 0, _ };

pub const Role = enum {
    mekwarrior,
    tech,
    medic,
    admin,

    pub fn baseSalary(self: Role) CBills {
        return switch (self) {
            .mekwarrior => 1_500,
            .tech => 800,
            .medic => 400,
            .admin => 500,
        };
    }
};

pub const Person = struct {
    id: PersonId,
    name: []const u8,
    role: Role,
    hired_day: u32,
    morale: i8 = 0,

    pub fn monthlySalary(self: Person) CBills {
        const bp: Bp = 10_000 + @as(Bp, self.morale) * 200;
        return applyBp(self.role.baseSalary(), bp);
    }
};

pub const Category = enum { payroll, severance, contract, event };

pub const Transaction = struct {
    day: u32,
    amount: CBills, // income +, expense -
    category: Category,
    note: []const u8 = "",
};

pub const Ledger = struct {
    transactions: std.ArrayList(Transaction) = .empty,

    pub fn post(self: *Ledger, alloc: std.mem.Allocator, txn: Transaction) !void {
        try self.transactions.append(alloc, txn);
    }

    /// Sum of every transaction: what the ledger says we have gained or lost.
    pub fn balance(self: Ledger) CBills {
        var total: CBills = 0;
        for (self.transactions.items) |t| total += t.amount;
        return total;
    }

    pub fn sumCategory(self: Ledger, cat: Category) CBills {
        var total: CBills = 0;
        for (self.transactions.items) |t| if (t.category == cat) {
            total += t.amount;
        };
        return total;
    }
};

/// Proleptic Gregorian date, as the game uses in 3025.
pub const Date = struct {
    year: u16,
    month: u8,
    day: u8,

    pub const campaign_start: Date = .{ .year = 3025, .month = 1, .day = 1 };

    pub fn isLeapYear(year: u16) bool {
        return (year % 4 == 0 and year % 100 != 0) or year % 400 == 0;
    }

    pub fn daysInMonth(year: u16, month: u8) u8 {
        return switch (month) {
            1, 3, 5, 7, 8, 10, 12 => 31,
            4, 6, 9, 11 => 30,
            2 => if (isLeapYear(year)) @as(u8, 29) else 28,
            else => unreachable,
        };
    }

    pub fn next(self: Date) Date {
        var d = self;
        d.day += 1;
        if (d.day > daysInMonth(d.year, d.month)) {
            d.day = 1;
            d.month += 1;
            if (d.month > 12) {
                d.month = 1;
                d.year += 1;
            }
        }
        return d;
    }

    pub fn isPayday(self: Date) bool {
        return self.day == 1;
    }
};

pub const Clock = struct {
    date: Date = Date.campaign_start,
    day_index: u32 = 0,

    pub fn advance(self: *Clock) void {
        self.date = self.date.next();
        self.day_index += 1;
    }
};

pub const Stream = enum(u8) {
    events,
    market,

    const count = @typeInfo(Stream).@"enum".fields.len;
};

/// One generator per subsystem, all derived from a single seed.
pub const Rng = struct {
    prngs: [Stream.count]std.Random.DefaultPrng,

    pub fn init(seed: u64) Rng {
        var self: Rng = undefined;
        for (&self.prngs, 0..) |*prng, i| {
            prng.* = std.Random.DefaultPrng.init(seed ^ (0x9E3779B97F4A7C15 *% (i + 1)));
        }
        return self;
    }

    pub fn roll2d6(self: *Rng, stream: Stream) u8 {
        const r = self.prngs[@intFromEnum(stream)].random();
        return r.intRangeAtMost(u8, 1, 6) + r.intRangeAtMost(u8, 1, 6);
    }
};

pub const Error = error{ UnknownPerson, EmptyName, OutOfMemory };

pub const Company = struct {
    arena: std.heap.ArenaAllocator,
    people: std.ArrayList(Person) = .empty,
    next_id: u32 = 1,
    funds: CBills,
    starting_funds: CBills,
    ledger: Ledger = .{},
    clock: Clock = .{},
    seed: u64,
    rng: Rng,
    log: std.ArrayList([]const u8) = .empty,

    pub const Options = struct {
        funds: CBills = 50_000,
        seed: u64 = 3025,
    };

    pub fn init(gpa: std.mem.Allocator, opts: Options) Company {
        return .{
            .arena = std.heap.ArenaAllocator.init(gpa),
            .funds = opts.funds,
            .starting_funds = opts.funds,
            .seed = opts.seed,
            .rng = Rng.init(opts.seed),
        };
    }

    pub fn deinit(self: *Company) void {
        self.arena.deinit();
    }

    /// Every allocation the company makes comes from here and dies in deinit.
    pub fn allocator(self: *Company) std.mem.Allocator {
        return self.arena.allocator();
    }

    pub fn find(self: *Company, id: PersonId) ?*Person {
        for (self.people.items) |*p| if (p.id == id) return p;
        return null;
    }

    fn today(self: *Company) u32 {
        return self.clock.day_index;
    }

    pub fn hire(self: *Company, name: []const u8, role: Role) Error!PersonId {
        if (name.len == 0) return error.EmptyName;
        const id: PersonId = @enumFromInt(self.next_id);
        self.next_id += 1;
        const owned = try self.allocator().dupe(u8, name);
        try self.people.append(self.allocator(), .{
            .id = id,
            .name = owned,
            .role = role,
            .hired_day = self.today(),
        });
        return id;
    }

    pub fn fire(self: *Company, id: PersonId) Error!void {
        for (self.people.items, 0..) |p, i| {
            if (p.id == id) {
                try self.postTransaction(.{
                    .day = self.today(),
                    .amount = -p.monthlySalary(),
                    .category = .severance,
                    .note = p.name,
                });
                _ = self.people.orderedRemove(i);
                return;
            }
        }
        return error.UnknownPerson;
    }

    /// The only way money moves: a ledger entry and the balance, in lockstep.
    pub fn postTransaction(self: *Company, txn: Transaction) Error!void {
        try self.ledger.post(self.allocator(), txn);
        self.funds += txn.amount;
    }

    pub fn monthlyPayroll(self: *Company) CBills {
        var total: CBills = 0;
        for (self.people.items) |p| total += p.monthlySalary();
        return total;
    }

    pub fn runPayroll(self: *Company) Error!void {
        const payroll = self.monthlyPayroll();
        if (payroll == 0) return;
        try self.postTransaction(.{
            .day = self.today(),
            .amount = -payroll,
            .category = .payroll,
            .note = "monthly payroll",
        });
    }

    pub fn logf(self: *Company, comptime fmt: []const u8, args: anytype) Error!void {
        const line = try std.fmt.allocPrint(self.allocator(), fmt, args);
        try self.log.append(self.allocator(), line);
    }

    /// A 64-bit fingerprint of everything that matters. Two companies with
    /// the same seed and the same commands must produce the same hash.
    pub fn hash(self: *Company) u64 {
        var h = std.hash.Wyhash.init(0);
        h.update(std.mem.asBytes(&self.clock.day_index));
        h.update(std.mem.asBytes(&self.funds));
        for (self.people.items) |p| {
            h.update(std.mem.asBytes(&p.id));
            h.update(p.name);
            h.update(std.mem.asBytes(&p.morale));
            h.update(std.mem.asBytes(&p.hired_day));
        }
        const n: u64 = self.ledger.transactions.items.len;
        h.update(std.mem.asBytes(&n));
        return h.final();
    }
};

/// The morale event: 2d6 on the events stream every day. Snake eyes and

            try co.logf("day {d}: a good day (rolled 12), morale +1", .{co.clock.day_index});
        },
        else => {},
    }
}

        const kind = it.next() orelse continue;
        if (std.mem.eql(u8, kind, "seed")) {
            co.seed = try num(u64, &it);
            co.rng = Rng.init(co.seed);
        } else if (std.mem.eql(u8, kind, "clock")) {
            co.clock.day_index = try num(u32, &it);
            co.clock.date = .{ .year = try num(u16, &it), .month = try num(u8, &it), .day = try num(u8, &it) };
        } else if (std.mem.eql(u8, kind, "funds")) {
            co.funds = try num(CBills, &it);
            co.starting_funds = try num(CBills, &it);
            co.next_id = try num(u32, &it);
        } else if (std.mem.eql(u8, kind, "rng")) {
            const i = try num(usize, &it);
            if (i >= Stream.count) return error.BadFormat;
            for (&co.rng.prngs[i].s) |*s| s.* = try num(u64, &it);
        } else if (std.mem.eql(u8, kind, "person")) {
            const id = try num(u32, &it);
            const name = it.next() orelse return error.BadFormat;
            const role = std.meta.stringToEnum(Role, it.next() orelse return error.BadFormat) orelse return error.BadFormat;
            const hired_day = try num(u32, &it);
            const morale = try num(i8, &it);
            try co.people.append(co.allocator(), .{
                .id = @enumFromInt(id),
                .name = try co.allocator().dupe(u8, name),
                .role = role,
                .hired_day = hired_day,
                .morale = morale,
            });
        } else if (std.mem.eql(u8, kind, "txn")) {
            const day = try num(u32, &it);
            const amount = try num(CBills, &it);
            const cat = std.meta.stringToEnum(Category, it.next() orelse return error.BadFormat) orelse return error.BadFormat;
            const note = try co.allocator().dupe(u8, it.rest());
            try co.ledger.post(co.allocator(), .{ .day = day, .amount = amount, .category = cat, .note = note });
        } else if (std.mem.eql(u8, kind, "log")) {
            try co.log.append(co.allocator(), try co.allocator().dupe(u8, it.rest()));
        } else {
            return error.BadFormat;
        }
    }
    return co;
}

fn num(comptime T: type, it: *std.mem.TokenIterator(u8, .scalar)) LoadError!T {
    const tok = it.next() orelse return error.BadFormat;
    return std.fmt.parseInt(T, tok, 10) catch error.BadFormat;
}

pub fn main(init: std.process.Init) !void {
    const io = init.io;
    const gpa = init.gpa;
    var out_buf: [4096]u8 = undefined;
    var stdout = std.Io.File.stdout().writer(io, &out_buf);
    const out = &stdout.interface;
    var in_buf: [1024]u8 = undefined;
    var stdin = std.Io.File.stdin().reader(io, &in_buf);

    var co = Company.init(gpa, .{});
    defer co.deinit();

    while (true) {
        try out.flush();
        const raw = try stdin.interface.takeDelimiter('\n') orelse break;
        const line = std.mem.trim(u8, raw, " \t\r\n");
        if (line.len == 0) continue;
        const cmd = parseLine(line) catch |e| {
            try out.print("> error: {s}\n", .{@errorName(e)});
            continue;
        };
        switch (cmd) {
            .sim => |c| {
                const result = execute(&co, c) catch |e| {
                    try out.print("> error: {s}\n", .{@errorName(e)});
                    continue;
                };
                switch (result) {
                    .hired => |id| try out.print("> hired {s} as {s} (id {d})\n", .{ c.hire.name, @tagName(c.hire.role), @intFromEnum(id) }),
                    .fired => try out.print("> fired {d}\n", .{@intFromEnum(c.fire)}),
                    .advanced => |n| try out.print("> advanced {d} days to {d}-{d:0>2}-{d:0>2}, funds {d}\n", .{
                        n, co.clock.date.year, co.clock.date.month, co.clock.date.day, co.funds,
                    }),
                }
            },
            .people => {
                for (co.people.items) |p| {
                    try out.print("> {d:>3}  {s:<10} {s:<10} morale {d:>3}  pay {d}\n", .{
                        @intFromEnum(p.id), p.name, @tagName(p.role), p.morale, p.monthlySalary(),
                    });
                }
                if (co.people.items.len == 0) try out.print("> nobody on the roster\n", .{});
            },
            .ledger => {
                for (co.ledger.transactions.items) |t| {
                    try out.print("> day {d}  {d}  {s}  {s}\n", .{ t.day, t.amount, @tagName(t.category), t.note });
                }
                try out.print("balance {d}\n", .{co.funds});
            },
            .log => {
                for (co.log.items) |l| try out.print("> {s}\n", .{l});
                if (co.log.items.len == 0) try out.print("> quiet so far\n", .{});
            },
            .save => |path| {
                save(io, &co, path) catch |e| {
                    try out.print("> save failed: {s}\n", .{@errorName(e)});
                    continue;
                };
                try out.print("> saved {s}\n", .{path});
            },
            .load => |path| {
                const loaded = load(io, gpa, path) catch |e| {
                    try out.print("> load failed: {s}\n", .{@errorName(e)});
                    continue;
                };
                co.deinit();
                co = loaded;
                try out.print("> loaded {s}: day {d}, {d} people, funds {d}\n", .{ path, co.clock.day_index, co.people.items.len, co.funds });
            },
            .quit => break,
        }
    }
    try out.print("> bye\n", .{});
    try out.flush();
}

Check your understanding

  1. Why is money an i64 and a percentage an integer number of basis points?
    AnswerFloats cannot represent most decimal fractions exactly, so sums drift. Integer C-bills and integer basis points make every computation exact and identical on every machine, which the golden master depends on.
  2. What does the arena buy the Company, and what does it cost?
    AnswerOne deinit frees everything, there are no per-object destructors, and references between records (a transaction's note pointing at a name) are always valid. The cost is that memory only grows until the company is destroyed.
  3. Why is Command a tagged union rather than a set of methods the REPL calls directly?
    AnswerA union value is data: it can be put in an array (a script), replayed, logged, compared, and run by any front end through one execute. The golden-master test is a script of commands.
  4. State the invariant that postTransaction protects.
    Answerfunds == starting_funds + ledger.balance() at all times, because the balance and the ledger change only together, in that one function.
  5. Why does the company that starts on January 1st not pay on day 0?
    AnswerPayroll runs inside advanceDay after the clock moves, so the first check happens on day 1 (January 2nd). The test "31 days crosses exactly one payday" pins this down.
  6. What kinds of bug does the golden-master test catch, and what does it not catch?
    AnswerIt catches any source of non-determinism: real-clock reads, OS-seeded randomness, unordered iteration, races, uninitialised memory. It does not catch wrong rules that are wrong deterministically; those need the ordinary unit tests.
  7. Why is the random stream state saved to the file?
    AnswerSo that a loaded company continues exactly as the unsaved one would have. Re-seeding from the seed alone would restart the sequence from day 0's position.
  8. Which parts of stage 6 receive an io, and which must never?
    Answermain, save and load take io. Nothing above the "pure core" line does: Company, execute, advanceDay and runEvents cannot touch the outside world because the parameter is not there.
What you learned.
  • Start a program with its vocabulary types, tested alone: integer money, basis points, typed IDs, enums with methods.
  • A state struct owns its memory through one arena; init/deinit/allocator(); copy every string you keep.
  • Commands are a tagged union and execute is the single entry point returning a Result or a named error.
  • Money moves through one function that writes the ledger and the balance together; the invariant is a test.
  • Time moves in advanceDay, a fixed sequence of phases; the calendar is a struct beside an integer day counter.
  • Randomness comes from a seeded, named-stream generator owned by the state; a hash and a golden-master test guard determinism.
  • Parsing, printing, saving and loading live at the edge, hold the io, and turn every failure into a message. Save the RNG state and prove round-trips with a hash.
