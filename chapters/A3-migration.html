Appendix A3. Zig 0.16 migration notes

This appendix is for the moment you paste something from a web tutorial and the compiler says a member does not exist. The left column is the form you will find in tutorials and answers written for Zig 0.9 to 0.14; the right column is the 0.16 form. Every right-hand form was compiled with Zig 0.16.0 in one program (a3_new.zig) while writing this page, and the left-hand forms that appear in A4 were confirmed to fail with the messages shown there. Where a chapter covers the topic, it is linked.

The three big changes. First, I/O is explicit: anything that touches the outside world takes an std.Io value, which main receives through std.process.Init (Chapter 33). Second, containers are unmanaged: ArrayList and the hash maps no longer store an allocator, so you pass one to every call that can allocate (Chapter 21). Third, casts infer their result type: @intCast(x), not @intCast(T, x) (Chapter 4). Most rows below are an instance of one of these.

A3.3 Language and reflection

Old form (tutorials)Zig 0.16
@intCast(u8, x), @floatFromInt(f64, n), @ptrCast(*T, p)const y: u8 = @intCast(x); or @as(u8, @intCast(x)). All casts infer the result type (A1).
@typeInfo(T).Struct.fields, .Enum, .Union, .Int, .Pointer@typeInfo(T).@"struct".fields, .@"enum", .@"union", .int, .pointer, .optional, .error_union, .@"fn": lower-case tags, quoted where they collide with keywords.
usingnamespace other;Gone. Re-export what you need by hand: pub const answer = other.answer;
@Type(.{ .Struct = … })Gone in 0.16 ("invalid builtin function"). Build types with generics (Chapter 26) instead.
for (items) |item, i|for (items, 0..) |item, i| (the index is a second iterable)
async, await, suspendNot in the language. Use threads (Chapter 36) or the std.Io interface.
pub fn format(self: T, comptime fmt: []const u8, options: std.fmt.FormatOptions, writer: anytype) !void, called by {}pub fn format(self: T, w: *std.Io.Writer) std.Io.Writer.Error!void, called by {f}. Plain {} on a struct does not call it.
std.fmt.format(writer, "…", args)try writer.print("…", args) on any *std.Io.Writer
std.testing.expectEqual(5, add(2, 3)) with an untyped literalStill compiles in 0.16 when the literal coerces to the actual value's type. If you see "expected type 'u32', found 'i32'", the two sides have different types; fix with @as(i32, 5) on the expected side.

A3.6 The check program

The right-hand forms above were all compiled in one file. The parts most likely to surprise you are reproduced here so you can paste them into a scratch file and confirm your installed compiler agrees:

const std = @import("std");

pub fn main(init: std.process.Init) !void {
    const io = init.io;
    const gpa = init.gpa;

    var out_buf: [1024]u8 = undefined;
    var out_w = std.Io.File.stdout().writer(io, &out_buf);
    const out = &out_w.interface;

    var list: std.ArrayList(u32) = .empty;
    defer list.deinit(gpa);
    try list.append(gpa, 1);

    const now = std.Io.Clock.now(.real, io);
    try out.print("ns {d}\n", .{now.nanoseconds});

    var dir = std.Io.Dir.cwd();
    var f = try dir.createFile(io, "a3_out.txt", .{});
    var fb: [128]u8 = undefined;
    var fw = f.writer(io, &fb);
    try fw.interface.print("line {d}\n", .{1});
    try fw.interface.flush();
    f.close(io);
    const data = try dir.readFileAlloc(io, "a3_out.txt", gpa, .limited(1 << 20));
    defer gpa.free(data);
    try dir.deleteFile(io, "a3_out.txt");

    var aw: std.Io.Writer.Allocating = .init(gpa);
    defer aw.deinit();
    try aw.writer.print("{d}-{s}", .{ 1, "x" });
    try out.print("allocating {s}\n", .{aw.written()});

    var mtx: std.Io.Mutex = .init;
    try mtx.lock(io);
    mtx.unlock(io);
    try std.Io.sleep(io, .{ .nanoseconds = 1 }, .awake);

    var child = try std.process.spawn(io, .{ .argv = &.{ "echo", "spawned" } });
    _ = try child.wait(io);

    try out.flush();
}
